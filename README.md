# Wordcaptor · 百变小译

一个浏览器扩展：骑着星杖的小魔法使待在页面角落，帮你读英文网页和 YouTube 视频。接你自己的模型，没有后端，没有会员。

- **只译正文。** 导航、代码、页脚不碰；只处理你快要读到的部分。
- **两种读法。** 翻译模式在每段下面用手写体写出译文；学习模式只批注你大概看不懂的词和短语，尤其是按字面理解会错的那些。
- **一个开关管所有页面。** 开着，打开英文页面就自动开始；关掉，哪儿都不出现。
- **设置用说的。** 对她说「译文口语一点」「我过六级了」「这个网站别来」，她会记住。
- **看不懂就问。** 选中一处英文点「？」，她在旁边写一句解释。
- **会了就封印。** 点一下批注，它变成一张牌收起来，以后不再标。
- **越读越淡。** 一条批注读过几次就慢慢变淡，最后只剩下划线；点掉的批注多了，她会自己把你的水平调高一档。
- **YouTube。** 打开视频自带的英文字幕，她换成中英双语，中文是手写体。自动生成的字幕没有标点和断句，她会先断成一句句再译。译文跟着播放往前准备，看过的不再花钱。

完整的行为说明、每项功能验证到什么程度，见 [docs/SPEC.md](docs/SPEC.md)。

## 安装

需要 Node.js（开发时用的是 26，更早的版本没有试过）。

```bash
npm install
npm run build
```

然后在 Chrome 打开 `chrome://extensions`，开启「开发者模式」，点「加载已解压的扩展程序」，选 `.output/chrome-mv3` 目录。

## 接模型

点工具栏图标右键里的「选项」，或第一次点小樱时自动打开的配置页：

1. 选一家服务。内置了 DeepSeek、智谱、Moonshot、阿里云百炼、火山方舟、硅基流动、OpenRouter、OpenAI、Anthropic、Gemini、Ollama，以及几家的 Coding Plan 套餐；其他服务选「自定义」，填 OpenAI 或 Anthropic 兼容的地址。
2. 填密钥。可用的模型会自动列出来。
3. 点「保存并测试连接」。

建议用不带思考的快模型：译文是边生成边写到页面上的，思考会让你等。

**关于 Coding Plan 套餐：** 各家的条款一般只允许在指定的编程工具里用，有的明确禁止其他方式调用。在这里用可能被拒绝，或不符合条款，请先看服务商的说明。

## 怎么用

| 操作 | 效果 |
| --- | --- |
| 点小樱，或按 `Alt+W` | 开始或暂停，对所有页面生效 |
| 鼠标移到她身上 | 左上角切换翻译 / 学习模式，「…」跟她说话，「×」让她别在这个网站出现 |
| 把她拖到一段话上 | 只处理那一段 |
| 选中英文，点「？」 | 写一句解释，点一下收起 |
| 学习模式里点批注 | 封印成牌，以后不再标 |
| 学习模式里 Alt + 点一段话 | 给出整段译文 |
| 翻译模式里 Alt + 点译文 | 重新翻译这一段 |
| 鼠标在导航栏、侧栏、表格上停一下 | 把那一块也处理了 |

## 开发

```bash
npm run dev         # 带热更新的开发模式
npm run typecheck
npm test            # 单元测试
npm run test:e2e    # 构建后在真实浏览器里跑端到端测试
```

连真实模型的测试默认跳过。要跑的话设置环境变量，会花一点钱（十几次很小的请求）：

```bash
WISP_TEST_API_KEY=你的密钥 npm test
WISP_TEST_API_KEY=你的密钥 npm run test:e2e
```

默认连 DeepSeek；`WISP_TEST_PROVIDER` 和 `WISP_TEST_MODEL` 可以换成别家，取值见 `src/lib/live.test.ts` 和 `e2e/live.spec.ts` 开头的说明。

代码结构：

- `src/lib/`：不依赖页面的逻辑，各有单元测试。正文提取（`extract`）、提示词和输出解析（`translator`）、模型调用（`llm`、`providers`）、写进页面（`render`）、缓存（`cache`）、批处理队列（`queue`）、字幕（`subtitles`）、存储（`settings`）、小樱（`sprite`、`sprite-art`）。
- `src/entrypoints/`：`background` 发模型请求，`content` 在页面里干活，`options` 是配置页。
- `e2e/`：端到端测试，带一个假的模型服务。
